# Focus the active codebase on tear-profile retrieval

AlphaPhant's active purpose is fully automated catalog matching through ear localization, ear segmentation, ear landmark detection, tear-profile extraction, and tear-profile matching. It returns one similarity score per known elephant; candidate ranking is the descending view of those scores. SEEK-code production and general elephant feature analysis are not part of this pipeline, so their runtime abstractions will be removed while historical source metadata may remain as research provenance.
