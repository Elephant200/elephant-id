# Repository File Tree

This file maps the local `elephant-id` repository, including ignored local files that are present in this checkout.
Very large generated, dependency, cache, VCS, and dataset directories are summarized with their major folders and representative files; the full local inventory includes hundreds of thousands of files because `dataset/` is very large, `apps/web/node_modules/` is about 496M, `.venv/` is about 425M, `apps/web/.next/` is about 96M, and `.git/` is Git's internal object store.

```text
elephant-id/
```
