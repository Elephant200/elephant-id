# Reference

Reference docs preserve technical detail that is useful but not core product guidance.

- [Tear-profile matching](matching.md) describes the current matching signal and evaluation shape.
- [Tear profile reference](tear-profile.md) preserves the design history behind the current tear-profile representation.
- [Timing notes](timing.md) capture a point-in-time performance profile for use when optimizing for speed.
- [Desktop app](desktop-app.md) records the design and workflow preferences for the `apps/desktop` reviewer.
- [Papers](papers/) contains SEEK and Curvrank source papers used as historical and technical references.

Core product direction lives in `docs/workflow.md` and `docs/architecture.md`.
